O problema

Os dados são públicos. Comparar, não.

  • Em 1930, Clyde Tombaugh descobriu Plutão comparando duas fotos do mesmo céu e vendo um ponto que mudou de lugar.
  • O SPHEREx, da NASA, fotografa o céu inteiro em infravermelho a cada seis meses, e os dados são públicos.
  • Só a anã marrom WISE 0855 tem 258 imagens, cada uma numa cor diferente, giradas, com pixels com defeito.
  • Para ver o que se moveu é preciso alinhar tudo pixel a pixel. Hoje, só um astrônomo consegue, e é céu demais para os astrônomos olharem sozinhos.

Ciência confiável

Os cinco alvos passam numa validação científica.

Barnard's StarAnda ~11″ para o norte em um ano, medido com erro de 0,02 px
