    Como ler

    Cada quadro soma as imagens que o telescópio SPHEREx fez deste pedaço do céu numa mesma época. Estrelas distantes ficam paradas; o que é próximo se desloca de uma época para outra, e estrelas variáveis mudam de brilho. O círculo vermelho marca onde o objeto deveria estar segundo os catálogos.

    Dados: NASA/JPL-Caltech/IPAC, missão SPHEREx (IRSA), releases DR1 e QR3. Posições: SIMBAD.
